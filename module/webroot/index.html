每行一条映射，支持 # 注释。保持 localhost 等基础条目；不要填写 URL、端口或通配符。最终校验由设备端完成。

!生效范围须知

  • 不是全局 DNS 开关。 私有 DNS、应用内 DoH 或自带解析器可能绕过系统 Hosts。
  • 检查 KernelSU 卸载设置。 “卸载模块 / Umount modules”可能让目标应用看不到模块挂载。
  • 缓存不会立即消失。 系统、浏览器及应用的 DNS 缓存可能继续返回旧结果。
